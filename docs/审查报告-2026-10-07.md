## 三、本次审查发现并修复的问题

| # | 问题 | 影响 | 状态 |
| --- | --- | --- | --- |
| 1 | **8 个方法在同一个类里重复定义**（Python 静默取后者） | `vote_scheduler` 的**新版被旧版覆盖** → 在线时长汇总/白名单回填/冻结清零实际跑的是旧逻辑 | ✅ 删重复（7 个完全相同 + 1 个旧版），后台任务已确认在跑新逻辑 |
| 2 | 新增模块 `bind_rules.py` **未加入部署清单** | `ModuleNotFoundError` → **机器人起不来** | ✅ 两个清单都已补；新增 `scripts/verify_deploy.py` 自检（会检查"main.py 导入的模块在远端是否存在"） |
| 3 | 绑定校验曾被塞进前一个 `except` 语句体 | 语法合法但**永不执行** → "已绑定还能再绑" | ✅ 规则抽成纯函数 `bind_rules.check_bind_request` + AST 测试固化防线 |
| 4 | 账本连接未关闭（`with sqlite3.Connection` 只提交不关闭） | 长期运行可能累积句柄 | ✅ 改为 `@contextmanager` + `finally close()`；仍有少量告警待收敛（见遗留） |
| 5 | `_shrink()` 死循环（字号有下限时条件永真） | 榜单卡无回复 | ✅ 已修 + 单元测试防回归 |
| 6 | 榜单标题把 markdown 串画进图（`##` + 与页码重叠） | 排版错乱 | ✅ 调用点改纯文本 + 渲染器清洗与限宽 + AST 测试防回归 |
| 7 | 在线时长始终取不到（包名/回包/枚举多层问题） | 功能不可用 | ✅ 三级读取（内存→文件→**直读 SQLite**）+ 插件 `All()` 改直连 SQL |

## 四、遗留风险与建议

1. **`ResourceWarning: unclosed database`（低危）**：分配点在 `economy_store.py:79`；14 处调用点都是 `with` 形式，怀疑与线程中创建/回收有关。CPython 会兜底回收，不影响运行；建议后续统一改为显式 `close()` 并加 `-X tracemalloc` 回归。
2. **未启用的模块**：`whitelist_users.py`（白名单"以人为主体"新表）目前只写不读，属预备数据；若要切换进服判定，需按"双读灰度"推进。
3. **B6 商店/特权**：尚未开发（钱包、流水、幂等、离线发货 `zse_mail` 均已具备）。
4. **越权审计遗留**（用户已确认暂不处理）：玩家查询邮箱可见、喊话无限制、备份列表公开、查背包任意玩家。
5. **部署纪律（已自动化）**：每次部署后跑 `py scripts/verify_deploy.py`（哈希一致 / 模块齐全 / 进程存活 / 无 Traceback）。
