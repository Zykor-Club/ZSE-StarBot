# QQ 机器人官方接口速查（API v2 · 2026-09 核实版）

> 来源均为官方文档 https://bot.q.qq.com/wiki/develop/api-v2/ （抓取时间 2026-09-21）
> 判新标准：文档含 `api-v2` + `openid` + `Access Token(QQBot)` 三个特征即为最新版。

## 1. 鉴权

- 打开接口统一域名：`https://api.bot.qq.com`
- 请求头：`Authorization: QQBot {ACCESS_TOKEN}`
- `Token` 字段鉴权 **已废弃**，需用 `AppID + AppSecret` 换取 Access Token
  （SDK `qq-botpy` 内部已自动完成换取与刷新）
- OpenID 机制：不同机器人取到的 `group_openid` / `member_openid` 均不同，
  群聊天场景统一用 openid 定位，不再直接使用 QQ 号

## 2. 入群申请相关接口（9/3 更新）

### 拉取申请列表（30 QPM，机器人需群管理员）

```
GET /v2/groups/{group_openid}/join_request_list
Query: cursor(分页游标), limit(默认20，最大50)
```

返回 `list`:
- `join_request_id`：申请 ID（审批时回传）
- `member_openid`：申请人 openid（审批接口路径参数）
- `username`：申请人昵称
- `verify_info.method`：`verify_message`（验证消息）/ `admin_review_qa`（管理员问答）
- `verify_info.review_qa_list[]`：`{question, answer}` ← 对应审核卡片里"问题/回答"
- `risk_tips`：平台安全提示语

### 审批申请（60 QPM，机器人需群管理员）

```
POST /v2/groups/{group_openid}/approval_join_request/{member_openid}
Body: {
  "op": "approve" | "decline",
  "join_request_id": "申请ID",
  "reject_reason": "拒绝理由（decline 时可填）",
  "add_to_member_blacklist": false
}
```

## 3. 群消息（9/3 更新）

```
POST /v2/groups/{group_openid}/messages
```

关键字段：
- `msg_type`：0=文本(content)，2=Markdown(markdown)，7=富媒体(media)
- `markdown.content`：Markdown 正文（对应消息类型文档）
- `keyboard`：内嵌键盘；自定义按钮填 `keyboard.content.rows`
- `msg_id` / `event_id`：被动回复二选一（事件 5 分钟内有效）
- 主动消息频控：Bot 60/qpm（未认证 30/qpm）；单关系 20/qpm；每群每日 1000 条

按钮结构（每个 Button）：
- `id`：按钮 ID，同一键盘唯一
- `group_id`：分组 ID，同一分组内点了一个按钮后其它按钮变灰（仅 type=1 生效）
- `render_data.label / visited_label / style`（style: 0灰线框 1蓝线框 3白底红字 4蓝底白字）
- `action.type`：0=跳转，1=回调按钮(数据传后台)，2=指令按钮(输入框插 @bot)
- `action.permission.type`：0=指定用户，1=仅管理员，2=所有人
- `action.data`：回调数据，type=1/2 必填
- `action.unsupport_tips`：低版本客户端提示文案

## 4. 按钮点击回调

- 事件：`INTERACTION_CREATE`（INTENT `INTERACTION` 1<<26），type=11 代表消息按钮
- 事件里 `data.resolved.button_data` = 发送按钮时填的 `action.data`
- 收到后必须调用 `PUT /interactions/{interaction_id}` 回应，否则客户端一直 loading
- 同一 interaction_id 只能回应一次，超时失效

SDK 封装：`api.on_interaction_result(interaction_id, code)`、事件回调 `on_interaction_create`

## 5. 群事件（INTENT GROUP_AND_C2C_EVENT 1<<25）

| 事件 | 含义 |
|---|---|
| GROUP_ADD_ROBOT | 机器人被拉入群 |
| GROUP_DEL_ROBOT | 机器人被移出群 |
| GROUP_MSG_RECEIVE | 群开启接收机器人主动消息 |
| GROUP_MSG_REJECT | 群关闭接收机器人主动消息 |
| GROUP_MEMBER_ADD / GROUP_MEMBER_REMOVE | 群成员加入/退出（1<<24，成员变更后轮询列表更准） |

## 6. 常用错误码

| 错误码 | 含义 |
|---|---|
| 304036 / 40034127 | 无 Markdown 模板权限 |
| 304037 | 没有发消息按钮组件的权限 |
| 304038 / 304039 / 305007 | 消息按钮组件不存在/解析错误/键盘样式参数错误 |
| 40034005 | 回复消息 msg_id 已过期 |
| 40034100 | 主动消息发送超过频控限制 |
| 40034101 / 40054003 | 机器人非群成员 |
| 40034105 | 主动消息发送失败，无权限（群关闭了主动消息） |
| 40054002 | 机器人被禁言 |
| 40054010 | 不允许发送 URL |
