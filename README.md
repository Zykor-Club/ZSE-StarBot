# ZSE-StarBot

**猫娘小梦** —— 基于 QQ 官方机器人平台的群管理与泰拉瑞亚服务器管理机器人，与配套 TShock 插件 [starZSEbot](https://github.com/Zykor-Club/TShockServerPlugin) 通过 WebSocket 长连接通信。

- 对接方式：QQ 开放平台官方 Python SDK（`qq-botpy`），API v2 + AccessToken 鉴权，WebSocket 长连接（非第三方框架）
- 服务器通信：自研长连接协议（插件侧连接本机器人的 `zse_server` 服务端口）
- 主要能力：入群审核、白名单（邮箱验证/设备登录批准）、四身份权限、多群联合、服务器管理、查背包出图、地图、远程指令、广播、进度查询与提醒、GitHub 动态推送

## 功能一览

- **入群管理**：轮询入群申请并发送审批卡片（批准/拒绝按钮）、入群引导卡（自动授予拉入者"高级管理员"+ 帮助/关于按钮）、退群自动冻结白名单
- **白名单系统**：邮箱验证码绑定玩家名、换设备登录批准（`登录`）、设备清空重登（`清空设备`）、进服 UUID 设备校验、冻结/解冻、进服时间记录、改名（`修改白名单`，不迁移存档 / 需重新确认登录 / 48 小时限一次）、邮箱改绑（`邮箱改绑`，原白名单作废后 24 小时内用新邮箱重新添加，超时自动回滚 / 7 天限一次）
- **权限系统**：四身份（高级管理员 owner > 服主 master > 管理员 admin > 普通群员 member），支持多高级管理员、互相设置身份、权限不足统一提示
- **多群联合**：星状模型（总群 + 子群），白名单/身份/权限/冻结数据归总群；联合区内服务器自动互相可见（网状，无需单独共享）、群信息（含联合标注）
- **服务器管理**：多台服务器接入与在线状态、`ping`、在线玩家查询、获取地图、远程执行服务器指令、喊话/联合广播、删除/归属校验
- **种子投票与重置**：种子投票（程序生成候选 / 玩家提案 / 在线时长加权计票 / 定时更新与自动截止；发起后卡片仅在本群预览，用 `推送投票` 手动推送到联合区所有群）、一键重置（导出存档 → 应用投票结果种子 → 重置世界 → 推送存档 zip）
- **查询**：查背包（渲染成图片，在线直读 / 离线读 SSC，含经济/职业/技能）、玩家查询（绑定信息）
- **进度查询与提醒**：进度查询出图（世界图标/进度、7 事件列、18 boss 网格：已击败次数 / 未击败 / 锁定解锁时间）、进度提醒（指定 boss 首杀播报）、进度解锁提醒（BossLock / ProgressControls 锁定 boss 解锁前 N 分钟倒计时推送）
- **GitHub 动态**：新 Issue / PR / Star 自动推送到群，`仓库` / `pr` / `issue` 随时查询（综述图）
- **邮件服务**：QQ SMTP 发送绑定验证码，含频率限制（4 分钟间隔 / 5 封封顶）与邮件池

## 指令一览

> 匹配命令前会自动清洗消息里的 @ 标记，"@机器人 在线"等写法同样可用；权限不足会返回统一的"权限不足"卡片。

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `帮助` / `关于` | 所有人 | 功能引导 / 机器人信息 |
| `群信息`（群资料） | 所有人 | 群 ID、联合群、白名单统计 |
| `权限查询`（身份查询 / 查看权限） | 所有人 | 查看自己的身份与命令所需权限 |
| `设置高级管理员 <玩家名>` | 高级管理员 | 追授高级管理员（目标需已绑定白名单） |
| `设置身份 <玩家名> <高级管理员/服主/管理员>` | 高级管理员 | 授予身份（白名单内玩家） |
| `取消身份 <玩家名> [角色]` | 高级管理员 | 取消身份（至少保留一名高级管理员） |
| `允许成员获取地图 [开/关]` | 管理员及以上 | 控制普通群员能否使用获取地图 |
| `允许查看在线玩家 [开/关]` | 管理员及以上 | 关闭后在线只显示人数、隐藏名单 |

### 多群联合

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `绑定联合群 <群ID>` | 高级管理员 | 发起联合（双方均未联合时成为总群，之后加入的为子群） |
| `解除联合群 <群ID>` | 高级管理员 | 子群脱离总群；总群解散全部子群 |

> 联合区内服务器**自动互相可见**（网状）：群里 `添加服务器` 后，同联合区所有群都能在 `服务器列表 / 在线 / 获取地图 / 喊话 / 远程指令` 里看到并使用它，无需单独共享；白名单统一用总群那一套。

### 服务器管理

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `添加服务器 <ip/域名> <端口> <绑定码>` | 服主及以上 | 绑定码在服务器插件控制台生成 |
| `删除服务器 <序号>` | 服主及以上 | 服主只能删自己添加的；其它群的服务器不可删（会提示归属群）；删除后联合区内都将不再可见 |
| `服务器列表`（列表 / 服务器） | 所有人 | 已接入服务器、版本号、在线状态、添加者（跨群服务器标注来源群） |
| `在线`（服务器在线） | 所有人 | 各服务器在线玩家与推图进度 |
| `ping <ip/域名> <端口>` | 所有人 | TCP 连通性测试 |
| `获取地图 <序号>` | 普通群员（群开关开启时）/ 管理员及以上 | 生成世界地图图片 |
| `喊话 <序号> <内容>` | 所有人 | 向指定服务器发全服消息 |
| `远程指令 <序号|all|*> <指令>`（远程执行） | 管理员及以上 | 在服务器执行指令并回传输出 |
| `广播 <内容>` | 服主及以上 | 向联合区所有群发公告卡片（发起群除外） |

### 种子投票与重置

> 投票卡 / 更新卡 / 结果卡会发布到该服务器所在**联合区的所有群**（投票卡需用 `推送投票` 手动推送）；每人最多 2 票（同一编号再次发送=取消，切换语义）；计票按在线时长加权——单账号在线满 50 小时（3000 分钟）每票 1.5 分，否则 1 分。

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `种子投票 [序号] [候选…]` | 服主及以上 | 发起种子投票：首个纯数字参数视为服务器序号（缺省 1）；候选用全角 `；` 分隔、组合内的种子用 `+` 连接；不填候选时由机器人读取插件种子列表随机生成；发起后卡片仅在本群预览，不自动推送到其它群 |
| `投票 <编号>` | 所有人 | 对编号投票；同一编号再次发送=取消（编号见投票卡） |
| `结束投票 [序号]` | 服主及以上 | 提前截止该服务器的投票并公布结果 |
| `推送投票 [序号]` | 管理员及以上 | 把进行中投票卡推送到联合区所有群；省略序号=当前群可见的最新进行中投票 |
| `查看投票 <序号>` | 所有人 | 把该服务器当前的投票卡发送到本群（进行中优先，无进行中则显示最近已结束一场）；发送成功只发卡片、不回复确认消息 |
| `重置 [序号]` | 服主及以上 | 导出存档 → 应用投票结果种子 → 重置世界 → 推送存档 zip |

> - 每台服务器同一时间最多一个进行中的投票；默认每 1 小时更新票数、24 小时自动截止；获胜判定依次比较**总分 → 票数 → 随机**（平票时结果注明「平分随机选取」）。
> - `重置` 联动顺序：① 先导出存档（失败即中止、可重试，**存档导出不依赖 AutoResetPlus**）→ ② 若存在「已结束且未使用」的投票结果则把获胜种子写入插件预设并标记已使用，否则走插件预设/随机 → ③ 触发重置 → ④ 把存档 zip 推送到联合区所有群并回执发起群；zip 内按「地图文件」（.wld）与「玩家存档」（.plr）两个文件夹整理。
> - 未安装 AutoResetPlus 时，`重置` 与 `种子投票`（随机生成候选）会返回错误卡，需手动指定候选。

### 白名单与设备

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `绑定邮箱 <邮箱>` | 所有人 | 发送验证码邮件（含频控） |
| `添加白名单 <玩家名> <验证码>` | 所有人 | 校验验证码并绑定玩家名 |
| `修改白名单 <新玩家名>` | 所有人 | 修改本人玩家名：不迁移游戏存档；原名登录记录清除（新名字须"进服一次→发`登录 新名字`→再进服"）；48 小时限一次 |
| `邮箱改绑 <新邮箱>` | 所有人 | 改绑绑定邮箱：原白名单立即作废，24 小时内用新邮箱重新走「绑定邮箱 → 添加白名单」完成改绑，超时自动恢复原白名单；7 天限一次（也支持 `改绑邮箱` 写法） |
| `登录 [玩家名]` | 所有人 | 批准自己绑定账号的待批准设备（仅一个待批准时可省略玩家名） |
| `清空设备 [玩家名]` | 所有人 | 清空本人已登录的全部设备（登录/清空设备数据联合区内所有群共用）：下次进服须重新登录批准（仅能清空绑定本人的记录） |
| `玩家查询 <玩家名>` | 所有人 | 绑定邮箱、加入白名单时间、最后进服时间 |

### 查询

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `查背包 <服务器序号> [玩家名]` | 所有人 | 渲染背包图片；省略玩家名查自己（60 秒内同目标复用缓存） |

### 进度查询与提醒

> 进度查询卡包含：世界图标 + 世界名 + 进度，左侧 7 事件列（入侵/月相事件），右侧 18 boss 6×3 网格（已击败显示击杀次数 / 未击败 / 被锁显示锁图标+解锁时间）。

| 指令 | 权限 | 说明 |
| ---- | ---- | ---- |
| `进度查询 <序号>` | 所有人 | 发送该服务器的进度图片卡 |
| `进度提醒 <序号> <boss名>` | 管理员及以上 | 该 boss 首次被击杀时向本群播报（boss 支持中文别名或英文 key，如 `月总` / `Moon Lord`） |
| `进度提醒列表` | 管理员及以上 | 查看本群已设定的进度提醒 |
| `取消进度提醒 <序号> <boss名>` | 管理员及以上 | 取消一条进度提醒 |
| `进度解锁提醒 <序号> <boss名> <分钟>` | 管理员及以上 | 服务器装有 BossLock / ProgressControls 时可用：解锁前 N 分钟（1~1440）推送倒计时卡片；重复设定覆盖旧值 |
| `进度解锁提醒列表` | 管理员及以上 | 查看本群已设定的解锁提醒 |
| `取消进度解锁提醒 <序号> <boss名>` | 管理员及以上 | 取消一条解锁提醒 |

> - 提醒设置每群 × 每服独立；仅播报首次击杀（世界重置后重新生效）；服务器离线时按最后一次同步时间处理；删除服务器自动清理其全部提醒。
> - 解锁提醒推送时间以插件的解锁时间为准，进入窗口后只发一次；设定时实时校验服务器可见性、插件安装状态与 boss 锁定状态。

## 部署

### 环境要求

- Python 3.10+（服务器实测 3.13）
- 依赖安装：`py -m pip install -r requirements.txt`（qq-botpy / PyYAML / Pillow / aiohttp）
- QQ 开放平台机器人（AppID + AppSecret），机器人需为**群管理员**（入群申请接口要求）

### 使用步骤

1. **填配置**：复制 `bot/config.example.yaml` 为 `bot/config.yaml`，填入 `appid` 与 `secret`
   （QQ 开放平台 https://q.qq.com → 你的机器人 → 开发设置）
2. **把机器人拉进群**（建议设为管理员），程序日志会自动打印该群的 `group_openid`，可复制回 `bot/config.yaml` 固化
3. **群内权限**：机器人需要「接收机器人消息/主动消息」权限（群主/管理员在群设置中开启），否则机器人收不到消息、主动卡片发不出去
4. **运行**：

   ```
   py bot/main.py
   ```

5. **（可选）Windows 开机自启**：参考 `scripts/server/register_task.ps1` / `scripts/server/start_bot.ps1` 注册计划任务（脚本内路径按实际修改）

### 部署脚本（可选）

`scripts/` 下的 `deploy_main_only.py`、`deploy_permissions.py`、`ssh_remote.py`、`deploy_lookbag_assets.py` 用于把机器人/插件/素材一键上传到 Windows 服务器（脚本会把 `bot/` 下的文件平铺上传到服务器 `C:\bot`，与服务器现有目录布局一致）：

1. 复制 `scripts/deploy_config.example.json` 为 `scripts/deploy_config.json`，填写 SSH 地址/端口/用户名/私钥路径（该文件不会入库）
2. 例如仅更新机器人代码：`py scripts/deploy_main_only.py`

`scripts/server/` 下是服务器端运维脚本（计划任务注册、机器人/TShock 启动与重启、依赖安装），按需上传到服务器使用。

### 配套插件（服务器侧）

服务器需要安装 TShock 插件 [starZSEbot](https://github.com/Zykor-Club/TShockServerPlugin)：

1. 把 `starZSEbot.dll`（及依赖 `linq2db.dll`）放入服务器 `ServerPlugins` 并重启
2. 插件控制台输出 6 位绑定码，在群里用 `添加服务器 <ip> <端口> <绑定码>` 完成接入
3. 插件的服务端地址填本机器人的 `地址:zse_server_port`

## 运行前提检查清单（缺哪个报什么错）

| 前提 | 不满足时的提示 / 错误码 |
| ---- | ---- |
| 机器人在群内且是群管理员 | 接口 401 / 无权限（如 11282 需管理员权限） |
| Markdown 权限 | `304036 无Markdown模板权限` |
| 按键/按钮权限 | `304037 没有发消息按钮组件的权限` / `305007 键盘样式参数错误` |
| 主动消息频控 | `40034100 超过频控限制`（Bot 60/qpm，单群 20/qpm，每群每日 1000 条） |
| 机器人不是群成员 | `40034101` / `40054003` |
| 群拒绝机器人主动消息 | `40034105 主动消息发送失败，无权限`（`GROUP_MSG_REJECT` 事件会打警告日志） |
| 群未开启"接收官方机器人消息" | 事件不会推送，机器人表现为"发指令不回"（查 botpy.log 中该群是否有消息到达） |

## 配置文件说明

`bot/config.yaml`（示例见 `bot/config.example.yaml`）：

| 配置项 | 说明 |
| ---- | ---- |
| `appid` / `secret` | 机器人凭证（必填） |
| `groups` | 监控群列表（`name` / `group_openid` / 可选 `owner_openid`），拉群后从日志获取 |
| `poll_interval_seconds` | 入群申请轮询间隔（秒，建议 >=10） |
| `apply_title` | 入群申请卡片标题中的组织名 |
| `zse_server_port` | 插件接入机器人的服务端口 |
| `bot_name` | 机器人称呼（邮件正文等） |
| `bot_openid` | 本机器人 openid（用于区分 @ 的是谁；留空自动学习） |
| `smtp` | 发件邮箱 / SMTP 授权码 / 验证码有效期 / 频控参数 |
| `github` | 监控仓库、轮询间隔、自动推送开关、访问令牌 |
| `vote` | 种子投票：`option_count` 随机候选数量（默认 6）、`update_interval_minutes` 票数卡更新间隔（分钟，默认 60）、`deadline_hours` 自动截止时长（小时，默认 24）、`bg_dir` 投票卡背景图目录（留空=复用查背包素材目录） |
| `device_check` | 设备登录校验：`enabled` 城市（IP 跨市级变动）校验总开关、`ip2region_xdb` ip2region 离线库路径（留空=bot 目录下 `ip2region.xdb`）、`city_max` 每条白名单记录的常用城市上限（LRU 淘汰） |

## 素材说明（查背包图标不入库）

查背包渲染所需的物品图标（约 6200 张）、Buff 图标（约 390 张）来自 [CaiBotLite](https://github.com/UnrealMultiple/TShockPlugin/tree/master/src/CaiBotLite)（GPL-3.0），背景图由群友提供，均**不随仓库分发**。

需要查背包出图时：

1. 从上述仓库获取 `images/items`、`images/buffs`、`terraria_data/item_id.json`
2. 在 `scripts/deploy_config.json` 中配置 `cai_assets_dir`（CaiBotLite 素材目录）与 `bg_dir`（背景图目录，jpg）
3. 运行 `py scripts/deploy_lookbag_assets.py`：自动生成 `item_names.json`（文字降级用）、打包并上传到服务器 `C:\bot\assets\lookbag`

未配置素材时，查背包会自动降级为文字卡（使用 `item_names.json` 的名称映射）。

进度卡素材（`assets/progress`：18 boss + 7 事件图标、33 个世界图标、`lock.png`）同样来自 CaiBotLite（GPL-3.0），**不随仓库分发**；运行 `py scripts/deploy_progress_assets.py` 打包上传到服务器 `C:\bot\assets\progress`。

白名单设备城市校验使用的 `ip2region.xdb` 离线库（来自 [ip2region](https://github.com/lionsoul2014/ip2region)，不入库）放到服务器 `C:\bot\ip2region.xdb` 即可；缺失时自动跳过城市校验，不影响进服。
